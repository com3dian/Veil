# Veil

A lightweight macOS menu-bar app for redacting screenshots. Paint over sensitive areas, then warp and blur them so the original content is unrecoverable.

## Features

- Lives in your menu bar — stays out of the way
- Automatically detects new screenshots
- Soft brush with adjustable feather and blur
- Warp tool pushes pixels along surface normals for realistic distortion
- Copy or save the result in one click

## Requirements

- macOS 13.0+
- Apple Silicon or Intel Mac

## Build

Open `Veil.xcodeproj` in Xcode and press ⌘R.
